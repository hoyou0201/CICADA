# CICADA Classroom

인천대 사이버캠퍼스(`lms.inu.ac.kr`)의 녹화·비대면 강의를 3D 강의실에서 다른 학생들과 함께 듣고, 칠판에 내 강의 영상을 띄우며 AI 교수님에게 질문할 수 있는 웹 서비스입니다.

## 배포 URL

- **Production**: https://wt-deploy-ebon.vercel.app

## 핵심 기능

- **3D 강의실 & 캠퍼스 이동**: 키보드(`WASD`·방향키)와 바닥 클릭으로 아바타를 움직이고, 여러 강의실과 학교 건물 복도를 오가며 캐릭터 프리셋·리액션을 바꿀 수 있습니다.
- **인천대 LMS 연동 & 샘플 모드**: 학번으로 로그인하면 수강 강의, 이번 주 영상 목록, 과제·영상 마감 일정을 한눈에 확인합니다. 로그인 없이 바로 체험할 수 있는 **샘플 모드**도 제공합니다.
- **칠판에 내 강의 영상 띄우기**: 선택한 LMS 강의 창을 브라우저 화면 공유로 받아 3D 강의실 칠판에 재생합니다. 실제 LMS 창에서 재생되므로 출석·진도율이 그대로 기록됩니다.
- **같은 방 실시간 함께 듣기**: 같은 강의실에 접속한 학생들의 아바타 위치와 상태를 실시간(Supabase Realtime)으로 동기화해 혼자 듣던 녹화 강의를 함께 듣는 경험을 만듭니다.
- **AI 교수님 질의응답**: 강의실 앞 AI 교수님에게 다가가거나 클릭해 현재 듣고 있는 강의 맥락으로 궁금한 점을 질문하고 답변을 받을 수 있습니다.
- **학교 공지 게시판**: 강의실 벽면 게시판에서 인천대 홈페이지 RSS 공지사항을 확인하고 원문으로 바로 이동할 수 있습니다.

## 개인정보 처리 안내

- **비밀번호는 LMS로만 전송**: 학번과 비밀번호는 브라우저에서 인천대 LMS(`lms.inu.ac.kr`)로 직접 전송되며, 본 서비스의 서버로 전송되거나 저장되지 않습니다.
- **토큰 브라우저 임시 보관**: 발급된 LMS 세션 토큰은 브라우저의 `sessionStorage`에만 저장되며 탭을 닫으면 즉시 삭제됩니다.
- **강의·화면 비공개**: 칠판에 띄운 강의 영상(`MediaStream`)과 수강 강의명·영상 제목은 내 브라우저 화면에서만 렌더링되며 다른 접속자나 서버로 전송되지 않습니다. 실시간 방에는 닉네임, 아바타 위치, 상태, 캐릭터 외형 정보만 공유됩니다.

## 실행 방법

### 1. 사전 준비

- **Node.js**: 20 이상
- **패키지 매니저**: `npm`

### 2. 환경 변수 설정 (선택)

`.env.example`을 참고하여 프로젝트 루트에 `.env.local` 파일을 만듭니다. 환경 변수가 없어도 샘플 모드 및 기본 기능은 동작합니다.

```env
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
# 서버 함수(api/professor.ts) 전용
ANTHROPIC_API_KEY=
```

### 3. 설치 및 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`으로 접속합니다.

### 4. 린트·테스트·빌드

```bash
npm run lint     # 코드 정적 검사 (oxlint)
npm test         # 계약·변환 단위 테스트 (Vitest)
npm run build    # 타입 검사 및 프로덕션 번들 빌드
```

## 대회 협업 키트 설명

3인 대회용 협업 저장소. 할 일을 사람에게 미리 나누지 않고 **작은 GitHub 이슈 풀**로 두고, 리더가 놀고 있는 에이전트에게 우선순위대로 일을 지시해 병렬로 처리한다. 상태는 [Plankton](https://plankton.hoyou.dev)에서 본다.

### 흐름

1. [대회 전 준비](docs/READY.md)를 확인한다.
2. 주제가 공개되면 스킬을 순서대로 쓴다: `contest-topic` → `contest-plan` → `contest-split`. 결과는 [docs/BRIEF.md](docs/BRIEF.md)와 GitHub 이슈에 쌓인다.
3. 리더가 일을 지시하면 작업 에이전트가 [AGENTS.md](AGENTS.md)의 작업 루프대로 일 하나를 만들고 합친 뒤 멈춘다. 시작 프롬프트는 [docs/PROMPTS.md](docs/PROMPTS.md).
4. 마지막 15%는 [발표 준비](docs/DEMO.md).

### 구성

| 경로 | 내용 |
| --- | --- |
| `AGENTS.md` | 모든 AI 도구가 따르는 규칙과 작업 루프 |
| `docs/BRIEF.md` | 계획의 단일 원본 (스킬이 채운다) |
| `.claude/skills/` | `contest-topic`, `contest-plan`, `contest-split` (준비), `contest-lead` (대회 중 리더 AI) |
| `.plankton.example.yml` | 팀원 설정 예시 (선택) |
