# 붙여 넣는 프롬프트

`<...>`는 채워 넣는다. 에이전트 이름은 서로 달라야 에이전트별 소요 시간이 따로 집계된다(예: `claude-code/w1`, `codex/w2`).

## 작업 에이전트: 지시된 일 하나만 하고 멈춤

```text
AGENTS.md를 읽고 작업 루프대로 일해줘. 내 에이전트 이름은 <이름>이야.
내게 지시된 일 하나만 하고, 끝나면 보고하고 멈춰. 다음 일을 스스로 고르거나 시작하지 마.
지시된 일이 없으면 "지시된 일 없음"이라고만 알려줘.
```

이슈 번호를 직접 줄 때:

```text
AGENTS.md를 읽고 작업 루프대로 이슈 #<번호>를 해줘. 내 에이전트 이름은 <이름>이야.
그 일 하나만 하고, 끝나면 보고하고 멈춰. 다음 일을 스스로 시작하지 마.
```

에이전트는 일을 끝내면 멈추므로, 리더가 다음 일을 지시한 뒤에 **같은 프롬프트를 다시 붙여** 실행한다.

## 리더 AI: 일 정하기

```text
/contest-lead 현황을 보고 놀고 있는 에이전트에게 다음 일을 지시해줘.
가동 중인 에이전트: <이름 — 소유자 GitHub 아이디, ...>
```

5분마다 점검하려면 `/loop 5m /contest-lead 점검해줘`. `PLANKTON_TOKEN`이 필요하다(레포 소유자만).
