# 발표 준비 (마지막 15%)

새 기능은 넣지 않는다. 시간 값은 `docs/BRIEF.md`의 시간표를 따른다.

## 체크
- [ ] 1분 시연 시나리오가 한 줄씩 적혀 있고, 처음부터 끝까지 한 번 실제로 해 봤다.
- [ ] 배포 URL에서 핵심 흐름이 동작한다 (로컬이 아니라 배포된 곳에서).
- [ ] 정상 / 빈 결과 / 오류 상태를 각각 화면에서 확인했다.
- [ ] 샘플 데이터를 쓴 곳은 화면에 샘플임이 표시돼 있다.
- [ ] 제출물, 제출처, 마감, 출처·라이선스 표기 요구를 다시 확인했다.
- [ ] 발표자와 시연자를 정했다 (가장 잘 설명하는 사람 / 실제 동작을 가장 잘 아는 사람).
- [ ] 시연이 실패할 때의 대체 수단(녹화 영상, 스크린샷)이 있다.

## 시나리오

배포 URL: https://wt-deploy-ebon.vercel.app (README·BRIEF 기준). 수동 배포라서 시연 전에 최신 코드가 올라가 있는지 확인한다.

이 시나리오는 아직 처음부터 끝까지 리허설하지 않았다(리허설은 H7, 체크 항목은 위에 그대로 둔다). 각 단계의 화면 문구는 코드와 실제 화면으로 확인한 것이다.

### 시연 전에 해 둘 것
- 시연 PC의 Chrome에서 LMS(https://lms.inu.ac.kr)에 **먼저 로그인**해 둔다. 안 하면 영상 창이 LMS 로그인 화면으로 열린다.
- 칠판에 띄울 영상 하나를 정해 두고 한 번 재생해 본다. 질문할 말(AI 교수님용)도 하나 정해 둔다.
- 심사위원이 입장할 기기는 PC나 노트북의 브라우저로 준비한다(모바일은 이번 범위 밖).
- 대체 녹화 영상 위치: (H7에서 찍은 뒤 여기에 적는다)

### 1분 시연 순서 (한 줄씩)
1. **0:00 로그인** — 학번·비밀번호로 로그인한다 → 내 이름이 뜨고 강의실 목록에 방마다 인원 수가 보인다. "비밀번호는 학교 LMS로만 가고 우리 서버에는 안 간다"고 말한다.
2. **0:10 강의실** — "7호관 301호"에 들어간다 → 오른쪽 "내 강의" 패널에 수강 강의, 이번 주 영상(완료/미완료), 다가오는 마감이 뜬다.
3. **0:20 칠판** — 영상 하나를 눌러 LMS 창을 열고, "칠판에 띄우기"에서 방금 열린 LMS 창을 공유한다 → 칠판에서 영상이 재생된다. "진도율은 LMS 창에서 그대로 기록된다"고 말한다.
4. **0:30 심사위원 QR 입장** — 왼쪽 아래 "QR 보기"를 띄운다 → 심사위원이 스캔해 들어와 "샘플로 둘러보기"(또는 로그인) 후 아무 강의실에 입장하면 초대한 방으로 자동으로 옮겨진다. 인원이 "2명"이 되고 서로 아바타로 보인다. 심사위원 화면의 칠판에는 내 영상이 없고 "강의를 골라 칠판에 띄우세요"가 보인다(영상은 내 화면에서만 그린다).
5. **0:45 AI 교수님** — 칠판 앞 교수님에게 다가간다 → 질문 창이 열린다. 정해 둔 질문 하나를 보낸다 → 교수님이 답한다. (고른 강의가 있으면 그 강의 이름이 맥락으로 붙는다)
6. **0:55 게시판** — 오른쪽 벽의 게시판을 누른다 → "학교 공지" 목록이 뜬다.

한 단계에서 10초 넘게 막히면 그 단계의 대체 수단으로 넘어간다. 1분을 넘기지 않는 것이 우선이다.

### 실패할 때 대체 수단
| 막히는 곳 | 화면에서 보이는 것 | 대체 |
| --- | --- | --- |
| 1. 로그인 | "LMS에 연결하지 못했어요. 샘플로 둘러볼 수 있어요" | "샘플로 둘러보기"로 들어간다. 화면에 "샘플 데이터"가 표시되니 "계정 없이 체험하는 샘플 모드"라고 말한다 |
| 2. 강의 패널 | "일부 정보를 불러오지 못했어요" 또는 빈 목록 | 받은 것만 보여 주고 넘어가거나 샘플 모드로 다시 들어간다 |
| 3. 칠판 | LMS 창에 로그인 화면이 뜸 / 화면 공유가 취소·거부됨 / 영상이 안 나옴 | 탭 공유와 창 공유 중 다른 쪽을 한 번만 더 해 본다. 그래도 안 되면 칠판 단계는 **녹화 영상**의 해당 구간을 튼다 |
| 4. QR 입장 | 스캔이 안 됨 / 인원이 "아직 혼자예요" | "초대 링크 복사"로 링크를 보내거나, 같은 링크를 다른 창에서 열어 혼자 두 번 입장해 보여 준다. 안 되면 녹화 영상 |
| 5. AI 교수님 | 답이 오지 않음 / 오류 | 녹화 영상의 해당 구간이나 미리 찍어 둔 답변 스크린샷을 보여 준다 |
| 6. 게시판 | 공지를 불러오지 못했다는 문구 | 스크린샷으로 대체한다 |
| 전체 | 배포 URL이 안 열림 / 네트워크 문제 | 처음부터 **녹화 영상 전체**를 튼다 |

샘플 모드는 모든 단계의 기본 대체 수단이다. 샘플로 보여 줄 때는 "샘플 데이터"라고 말로 밝힌다.
